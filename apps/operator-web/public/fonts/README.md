# Bundled typography

Manrope variable (normal, 200–800) and IBM Plex Mono regular (normal, 400). Unmodified upstream TTF files; no remote font fetching. IBM Plex Mono regular is the only bundled mono weight; additional weights require separate review. Browser fallbacks/synthesis may apply for other styles.
