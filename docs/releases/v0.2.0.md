# VoltGrid v0.2.0 — Local Operator Console

This release completes the local operator workflow on top of the v0.1.0 backend. Java services, GraphQL contracts, OCPP, Kafka, database migrations and Terraform are unchanged.

## Operator capabilities

- Station dashboard with fleet search, connectivity filters and network totals.
- Station/connector details, transaction ledger with server filters and pagination, transaction lifecycle, completeness and meter inspection.
- Operations projection view with status filtering, cursor navigation and eventual-consistency context.
- Shared responsive navigation, refresh controls, keyboard focus/skip navigation, readable action links, recovery screens and true detail-record 404s.
- Optional local station registration with validation, duplicate handling and explicit uncertain-outcome guidance. Disabled by default; enable OPERATOR_LOCAL_WRITES=true only with a local HTTP Station API. Console dev/start bind to loopback. This is a local demo gate, not production user authentication.
- Runtime GraphQL validation, five-second request deadlines, unavailable/empty/not-found distinctions and hidden backend errors.
- Reproducible Webpack build with system fonts, client tests, browser regression CI and a disposable real-stack browser test.

## Verification

33 client regression tests; 11 Chromium fixture scenarios; production build/type checks and full lint. Real-stack browser verification covers registration, OCPP boot/authorization, transactional outbox, Kafka, Operations projection, complete transaction inspection and filtered ledger navigation.

Unchanged backend verified during this implementation session: 136 Station, 20 Authorization, 29 Operations and four real-process authorization-flow tests; all passed.

## Run locally

See ../../apps/operator-web/README.md for startup and verification commands. Use compose.operator-test.yaml with a dedicated disposable Compose project for live tests.

## Release limits

No cloud deployment or production mutation is included. New Docker service image rebuilds could not be verified in this environment because registry DNS failed; the real-stack check uses cached runtimes with freshly built, Maven-verified JARs mounted read-only. No chart claims or network totals are inferred from paginated projection data. There are no remote charging commands, destructive station mutations or token administration screens because the backend contract does not expose those operator capabilities.
