# VoltGrid

VoltGrid is a distributed EV Charging Network Platform / Charging Station
Management System (CSMS) built as a learning-focused backend engineering project.

## Learning Goals

VoltGrid will be developed incrementally while learning:

- Microservices architecture
- Spring Boot
- JPA / Hibernate
- gRPC and Protocol Buffers
- GraphQL
- OCPP and WebSockets
- Apache Kafka and event processing
- Distributed-system reliability patterns
- OpenTelemetry
- Terraform
- AWS

## Development Approach

VoltGrid is built through very small, independently understandable features.

Each completed feature is committed separately so the Git history reflects
how the system evolved.
